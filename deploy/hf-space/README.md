# Desire Paths

Agent cost per task falls as your graph is used. This Space runs the open-source **HydraDB** engine (v0.4.0, built
from source) and the Desire Paths dashboard in one container: live questions, learned routes as single HydraDB
queries, and a live "change one fact" heal demo.

Code, results and how to reproduce: https://github.com/Jmohak2004/desire-paths
